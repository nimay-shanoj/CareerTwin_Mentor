Frame format

The raw TCP protocol, in the same order as the bytes on the wire.

MAGIC
0x4354 VER
0x01 LENGTH
u32 PAYLOAD (JSON, UTF-8)
  • HELLOAuthenticate with a single-use token
  • WELCOMEServer greeting + heartbeat interval
  • SENDSend a message (idempotent by client id)
  • ACKServer confirms and assigns a sequence
  • MSGAn incoming message
  • READRead receipt
  • TYPINGTyping indicator
  • PINGKeepalive probe
  • PONGKeepalive answer
  • PRESENCEUser online / offline
  • ERRError with a stable code
  • BYEGraceful close
